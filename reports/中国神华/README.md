## 核心结论速览

**综合评分：3.3 / 5** —— 好而不伟大的生意 × 欠佳的当前价格（A股）

- **一句话**：全球最低成本 + 煤电路港航一体化 + 74-79%高分红兑现，是"经20年验证把真金白银还给股东"的央企；但无差异化、无定价权、2030后需求确定下行。**生意与制度值得托付，但 A 股 46 元不是好价格；H 股折价15-20%、股息率~5.3% 更接近合理价。**
- **四维评分**：商业模式 ★★★（段永平）/ 财务估值 ★★★（巴菲特）/ 行业竞争 ★★★（芒格）/ 风险管理 ★★★★（李录）
- **击球点**：A股 <40元 / H股 <40港元（对应股息率 >5-5.5%）；现价定位="值得跟踪研究的高息现金流资产"，非"成长复利机器"
