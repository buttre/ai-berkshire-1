## 核心结论

**好公司、错价格：观望。** 恒瑞是A股稀缺的好公司——创新转型真实（创新药占比38%→63%）、387亿现金零有息负债、全球唯一被GSK与BMS双双打包选中的研发平台。但2026H1营收扣非双降（-1.94%/-12.71%）暴露增长换挡阵痛，利润约三成来自浮盈与利息；41倍PE无安全边际（中性情景隐含年化回报仅6.2%）。

**操作参考**：A股40元以下（对应H股约40港元以下）或基本面重新验证（BMS首付确认后扣非回正、GLP-1获批、FDA放行任一品种）之前，不下注。风险信号：扣非再度负增长、FDA第四次CRL、地缘名单波及BMS交易。
